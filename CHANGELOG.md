# Changelog

## 0.1.0 (2026-11-26)

- Key parser for Camelot, Open Key, letter names with sharps/flats/unicode, Spanish and Portuguese solfège.
- Moves from a key (safe, energy, creative), symmetric key distance.
- Mashup check with half/double-time tempo matching and best pitch shift.
- Set planner (greedy + 2-opt) reading CSV or JSON, compatible with bpm-key-finder output.
- CLI: key, mix, shift, set, wheel (en/es/pt); agent skill files.
