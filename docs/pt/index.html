Perguntas frequentes

O que é a roda Camelot?

Uma tabela que dá a cada um dos 24 tons um código de 1A a 12B. O número é a posição num relógio (cada passo é uma quinta) e a letra é o modo: A é menor, B é maior. DJs usam para escolher músicas cujos tons combinam.

Quais tons Camelot combinam?

A partir de qualquer código: o mesmo, um número acima ou abaixo com a mesma letra, e o mesmo número com a outra letra. Dois passos acima (+2) ou sete (+7, um semitom) aumentam a energia em transições curtas.

Qual a diferença entre Camelot e Open Key?

A mesma ideia com outros rótulos. O Open Key (Traktor) começa em Dó maior = 1d e Lá menor = 1m; no Camelot Dó maior = 8B e Lá menor = 8A.

Mudar o pitch muda o código Camelot?

Sim. Um semitom acima soma 7 (8A vira 3A). Sem key lock, acelerar a música uns 6 % sobe cerca de um semitom.

Como descubro o tom das minhas músicas?

Use o detector de BPM e tom grátis: solte as músicas e ele mostra o código Camelot de cada uma.
