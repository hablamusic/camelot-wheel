FAQ

What is the Camelot wheel?

A chart that gives each of the 24 musical keys a code from 1A to 12B. The number is the position on a clock (each step is a fifth), the letter is the mode: A is minor, B is major. DJs use it to pick songs whose keys blend.

Which Camelot keys mix together?

From any code: the same code, one number up or down with the same letter, and the same number with the other letter. Two steps up (+2) or seven steps (+7, one semitone) boost the energy in short transitions.

What is the difference between Camelot and Open Key?

Same idea, different labels. Open Key (used by Traktor) starts at C major = 1d and A minor = 1m, while Camelot has C major = 8B and A minor = 8A.

Does changing the pitch change the Camelot code?

Yes. One semitone up adds 7 (8A becomes 3A). Without key lock, speeding a song up by about 6% raises it one semitone.

How do I find the key of my songs?

Use the free BPM and key finder: drop your songs and it gives the Camelot code of each one.
